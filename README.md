# SoE Activities

A collection of interactive HTML activities built for the School of Education. Self-contained, embeddable components for use in an LMS or web platform across teaching and education units.

---

## Live Activities

Each activity is hosted via GitHub Pages and can be linked or embedded directly into an LMS.

### Professional Experience

| Activity | Description | Live Link |
|---|---|---|
| Teaching Strategy Review | Interactive infographic exploring instructional and collaborative teaching strategies. | [Open](https://hum-edtt.github.io/soe-activities/professional-experience/teaching-strategies.html) |
| Lesson Builder — Novice | Drag-and-drop hurdle task: build a novice-format lesson plan from a bank of teaching strategies. | [Open](https://hum-edtt.github.io/soe-activities/professional-experience/lesson-builder-novice.html) |
| Lesson Builder — Expert | Drag-and-drop hurdle task: build an expert-format lesson plan from a bank of teaching strategies. | [Open](https://hum-edtt.github.io/soe-activities/professional-experience/lesson-builder-expert.html) |

## About this repository

- **Hosting:** GitHub Pages (free, public)
- **Format:** Self-contained HTML files — no external dependencies, no build step
- **Compatibility:** Modern browsers (Chrome, Edge, Firefox, Safari). Mobile-responsive where applicable.
- **Embedding:** Designed for iframe embedding into LMS platforms (Blackboard Learn, Canvas) or direct linking.

## Folder structure


## Adding a new activity

1. Upload the new `.html` file into the appropriate subject-area folder.
2. Edit this README and add a row to the relevant table above.
3. Commit. Live URL is available within ~1 minute via GitHub Pages.
